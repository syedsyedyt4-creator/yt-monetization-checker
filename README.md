# 🚀 MonetizeHub - YouTube Monetization Checker & Creator Hub

A high-converting web platform designed for ad revenue (Google AdSense, Ezoic, Mediavine, and creator affiliate sponsorships). 

## 🌟 Features Included

1. **YouTube Channel & Video Monetization Checker**
   - Paste any channel URL (`youtube.com/@handle`), `@username`, channel ID, or direct video URL.
   - Detects live monetization status using YouTube streaming player ad signals (`yt_ad: 1`, `adPlacementConfig`, and YPP metadata).
   - Displays Subscriber counts, verified status, estimated monthly ad revenue, yearly revenue, and niche average RPM.
   - Live technical verification checklist breakdown.
   - Confetti celebration animation for monetized channels.

2. **Today's Viral Faceless Niches**
   - Curated list of high-RPM, trending faceless YouTube & TikTok niches (Dark History, Financial Psychology, Reddit Stories, AI Tech, Cozy ASMR, Stoic Mindset).
   - Real estimated RPM ($4.00 - $28.50).
   - Filter by: Highest RPM ($10+), Fastest Growth, and Low Competition.
   - AI Tool Stacks (Script, Voice, Visuals, B-Roll, Editing).
   - Expandable step-by-step production blueprints.

3. **Trending Keywords & Viral Hashtags**
   - Categorized by hot niches (Faceless Shorts, AI & Tech, History & Mysteries, Finance, Psychology).
   - Search volume and competition indicators.
   - **1-Click "Copy All Tags" for YouTube Studio**: Copies tags pre-formatted with commas so creators can paste directly into the YouTube Studio upload box.

4. **Interactive YouTube Revenue / RPM Calculator**
   - Interactive sliders for daily views (1,000 to 500,000+) and niche RPM selectors.
   - Computes daily, monthly, and annual ad income in real-time.

5. **AdSense & Ad Monetization Engine**
   - Responsive **Leaderboard Ads** (728x90 desktop / 320x50 mobile).
   - **In-Feed Native Ads** placed below checker results and within niche grids.
   - **Sticky Bottom Anchor Ad Bar** with high viewability and close button.
   - **Day-1 Monetization**: Fallback high-converting creator affiliate links (ElevenLabs, CapCut) are active immediately so you can start earning before AdSense approval!
   - Ready to plug your Google AdSense Publisher ID (`ca-pub-XXXXXXXXX`).

6. **AdSense Compliance & Policy Kit** (Strictly required for Google approval)
   - Privacy Policy (with Google DART cookie and GDPR disclosures)
   - Terms of Service
   - About Us
   - Interactive Contact Us form (connected to backend)
   - Independent Legal Disclaimer
   - GDPR/CCPA Cookie Consent Banner

## 🛠️ How to Run Locally

### Start the All-in-One Server:
```bash
npm start
```
Open **[http://localhost:5000](http://localhost:5000)** in your browser!

### Running in Development with Hot-Reload:
1. Start API Server:
   ```bash
   node server/index.js
   ```
2. Start Frontend Dev Server:
   ```bash
   npm run client
   ```
   Open **[http://localhost:5173](http://localhost:5173)**!
